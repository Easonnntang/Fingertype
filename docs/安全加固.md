# 安全加固（可选，不可逆）

默认的 Fingertype 固件已经做到：密码只写不读、修改要验证指纹、密码加密保存。但**加密钥匙默认也存在闪存里**，所以拿到实物、又懂技术的人，可以把闪存整个读出来再解密（详见 README 的安全说明）。

ESP32-S3 芯片里有一小块**只能写一次**的存储，叫 eFuse（熔丝）。写进去就永远改不了、擦不掉。用它可以把安全性再提高一层。

> ⚠️ 以下操作全部**不可逆**。操作失误可能让开发板再也无法刷机或启动。请先读懂乐鑫的官方文档，并在一块备用板上试过以后，再决定是否用在日常使用的设备上。本项目不对任何损坏负责。

## 三个选项

| 选项 | 防的是什么 | 对以后编译 / 刷机 / 升级的影响 |
|---|---|---|
| **A. 把加密钥匙放进 eFuse**（设置为软件读不出，只能交给芯片的 HMAC 硬件使用） | 别人把闪存读出来，也解不开密码 | 没有影响 |
| **B. 闪存加密** | 整块闪存读出来都是乱码 | 网页升级照常；USB 刷机要多一个加密步骤；需要改用支持该功能的编译方式（Arduino 默认的引导程序不支持） |
| **C. 安全启动** | 只运行签过名的固件，别人刷不进改过的固件 | 每个固件都要用你自己的私钥签名；**私钥丢了，这块板子就永远无法再升级**；同样需要改编译方式 |

### 只做 A 还不够的地方

A 能防住“把闪存读出来”，但防不住“拿到实物后，用数据线刷一个自己写的固件，让芯片帮他解密”。要防住这一点：

- 做 C（安全启动）；或者
- 再烧一个 eFuse，关闭 USB 刷机模式。因为固件可以在设置网页里升级（需要验证指纹），关掉 USB 刷机后，别人就刷不进固件了。代价是：如果某次升级的固件一开机就崩溃，也无法再用 USB 救回来。

## 当前状态

- 固件**还没有**内置 A。计划以后在设置网页的「高级设置」里加一个开关，由用户自己确认后再烧写；每块板子会随机生成只属于自己的钥匙，并把已经存好的密码自动重新加密。
- B、C 需要使用者用自己的签名私钥、按乐鑫官方文档手动操作。**本项目不会、也不应该发布任何共用的签名私钥。**
