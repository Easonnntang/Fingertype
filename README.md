# Fingertype

Macbook作为主机使用，盒盖时就无法指纹解锁；Mac mini 和 Mac Studio 也一样。如果不买 Apple 带触控 ID 的妙控键盘，每次点亮屏幕都要手动输入密码。妙控键盘太贵，手动输入太繁琐。

所以 Fingertype 来了。全程由 Claude 制作，包括外壳的建模。

对于 Mac 来说，它就是一个蓝牙键盘：识别到录入的指纹后，就像键盘一样输入事先存好的密码，然后自己按回车，一按即可。同时也可以绑定各种快捷键，比如锁屏、截图。

- 不用装任何 App，设置全在一个本地网页里完成。
- 指纹的录入和比对都在指纹模块内部完成，指纹数据不会离开模块。
- 密码只能写入、不能读出，设备不会把密码传回电脑。
- 日常靠蓝牙通信，Type-C 只接充电头供电；插着数据线时自动改用 USB 键盘输出。
- 固件可以直接在设置网页里导入升级，蓝牙或 USB 都行。
- 没有做自带电池的版本，因为不想让它体积再变大。当然你们想的话，可以自己捣鼓。
- 本体就是一块 ESP32 加一个指纹识别模块。如果愿意，可以用 3D 打印机给它做出各种外观。
- 可以直接刷入我的固件，也可以让你的 AI 助手帮你从头写一个，把这个项目丢给它就行。
- 我是一个完完全全不懂编程和建模的人，有任何问题请直接告诉我。

> English: Fingertype is a fully open-source fingerprint unlocker for Macs used with the lid closed, or for a Mac mini / Mac Studio without a Touch ID keyboard. To the Mac it is just a Bluetooth keyboard: when it recognizes your finger, it types your stored password and presses Return. You can also bind fingers to shortcuts such as lock screen or screenshot. Built on a Seeed XIAO ESP32S3 + HLK-ZW111 fingerprint module; all setup happens in a local web page, no app needed. The whole project, including the 3D-printed case, was made with Claude by someone with no programming or modeling background. Documentation is currently in Chinese.

**使用前请先阅读下面的[安全说明](#安全说明请在使用前阅读)。**

## 安全说明（请在使用前阅读）

Fingertype 会把你的电脑密码存在设备里。请先了解它的保护范围。

**设备在你手里时**
- 设置网页、USB、蓝牙都没有“读取密码”的功能：密码存进去以后，只能被覆盖或删除，不会通过任何连接传回电脑。
- 设备里有指纹之后，所有修改都要先在设备上验证指纹（包括升级固件）。
- 指纹的录入和比对都在指纹模块内部完成，指纹数据不会离开模块。
- 只接受配对过的电脑；连续验证失败会锁定，而且锁定时间越来越长，断电重启也绕不过去。
- 密码在设备里是加密保存的（AES-256-GCM）。

**建议**
- 把它当成一把**电脑的钥匙**来保管，放在你信任的环境里使用（比如家里）。
- **设备遗失，请立即修改电脑密码**，现在借助 AI agent，拿到实物即有可能破译密码。
- 完全不建议存放各种重要账号密码。
- 需要更高安全性的，可以用 ESP32-S3 的 eFuse 功能加固（把钥匙放进熔丝、闪存加密、安全启动）。这些操作**不可逆**，操作失误可能让开发板无法再使用，请在充分了解后自行决定，见 [docs/安全加固.md](docs/安全加固.md)。
- 所有的操作和风险，都可以直接询问你的AI agent。

本项目按“现状”提供，不对任何密码泄露或损失负责（见 [LICENSE](LICENSE) 中的免责条款）。

## 需要的硬件

| 零件 | 说明 |
|---|---|
| Seeed Studio **XIAO ESP32S3** | 买“已焊排针”或“不焊排针”的都行；记得带上配套的天线 |
| 海凌科 **HLK-ZW111** 指纹模块 | ZW101 也适用（同一套串口协议） |
| 杜邦线 / 模块自带的排线 | 6 根 |
| USB-C 数据线 | 刷固件、第一次设置时用 |
| USB 充电头 | 日常供电 |

外壳的 3D 打印文件发布在 MakerWorld（链接待补充）。

## 接线

| 指纹模块 | 接到 XIAO |
|---|---|
| VCC（3.3V） | 3V3 |
| 触摸电源（3.3V） | **D3**（GPIO4，固件让它输出 3.3V） |
| GND | GND |
| TX（模块发送） | **D7**（GPIO44） |
| RX（模块接收） | **D4**（GPIO5） |
| 触摸输出（手指按下为高电平） | **D1**（GPIO2） |

> ⚠️ 不同批次的模块线色可能不同，请以模块的说明书为准。上电前对照确认，**不要把 3.3V 和 GND 接反**。
>
> - 模块 RX **不要接 D6**：D6 是 ESP32 开机打印日志的引脚，会让模块通信错位，而且模块不断电就一直错下去。
> - XIAO 只有一个 3V3 引脚，所以触摸电源由 D3 供电（触摸检测电路耗电极小），全程不用焊接。
> - 触摸输出目前只是预留：固件默认每 40 毫秒直接询问模块有没有手指，比触摸脚反应更快。

## 刷入固件

### 方法一：直接刷编译好的固件（推荐）

在 [Releases](../../releases) 下载两个文件：
- `Fingertype-vX.Y.Z-full.bin`：第一次刷机用，包含引导程序和分区表；
- `Fingertype-vX.Y.Z-update.bin`：以后在设置网页里升级用。

用数据线把 XIAO 接到电脑，安装乐鑫官方的刷机工具 [esptool](https://docs.espressif.com/projects/esptool/)（`pip install esptool`），然后执行：

```bash
esptool --chip esp32s3 write-flash 0x0 Fingertype-vX.Y.Z-full.bin
```

找不到设备时：**按住板子上的 B（BOOT）键，再插数据线**，进入刷机模式后重新执行。刷完拔插一次数据线。

> `full.bin` 会覆盖整块闪存的开头部分，**包括设备里存的指纹绑定、密码和蓝牙配对**。已经在用的设备请用设置网页升级，不要再刷 `full.bin`。下载后可以用 `SHA256SUMS.txt` 核对文件是否完整。

> 不熟悉命令行也没关系：可以直接让你的 AI agent（比如 Claude Code）帮你完成这些步骤，把这一节发给它就行。

### 方法二：自己编译

需要 [PlatformIO](https://platformio.org/)（Mac 上可以 `brew install platformio`）。

```bash
pio run                 # 编译
pio run -t upload       # 刷入（XIAO 用数据线接电脑）
```

> 不熟悉命令行也没关系：可以直接让你的 AI agent（比如 Claude Code）帮你完成这些步骤，把这一节发给它就行。

### 方法三：让 AI 帮你做一个属于你自己的版本

如果不想使用我发布的内容，可以让你的 AI agent 帮你从无到有做一个独属于你自己的版本，加入你自己的想法、习惯和审美。

把这份文档（或者整个仓库）丢给你的 AI agent，然后开始畅想你的版本。

### 以后升级

在设置网页的「高级设置 › 设备信息」里点「升级固件」，选择 `update.bin` 即可。USB 约 25 秒；蓝牙要 30 分钟左右，建议用数据线；开始前要先验证一次指纹。全部收完、校验通过后，设备才会切换到新固件，中途断开或出错，原来的固件不受影响。

## 第一次设置

### 打开设置页面：配置盘

用数据线把设备接到电脑上，会出现一个只读 U 盘 **FINGERTYPE**，里面有两个文件：
- **Settings.html**：设置页面（编译固件时自动嵌入，永远和固件版本一致）；
- **重要文件请先阅读.txt**：使用说明。

配置盘什么时候出现：
- **还没录任何指纹时**：一插上就会出现。
- **录过指纹之后**：插着数据线，用「设置入口指纹」长按 5 秒才会出现。录完第一枚指纹后，网页会提示你设置入口指纹；只录了一枚时，自动使用这一枚。
- 在访达里推出后，它会隐藏，直到下次再打开。

建议把 Settings.html 复制到电脑上常用的文件夹，用 Chrome 打开并存为书签，以后点书签就能进入设置（复制后不要再移动文件）。升级固件后，请从配置盘重新复制一份，覆盖旧文件。

### 设置步骤

1. 用 **Chrome 或 Edge** 打开 Settings.html（Safari 不支持网页蓝牙）。
2. 先在电脑的蓝牙设置里连接 **Fingertype**（第一台电脑可以直接配对），再在网页上点「通过蓝牙连接」。第一次使用时 Chrome 会请求蓝牙权限。
3. 在「密码管理」里添加密码（例如电脑登录密码）。
4. 在「指纹管理」里录入指纹：填名称、选择识别后的操作，按提示按压 4 次。任意一根手指可以绑定任意操作：输入某个密码、按一个快捷键（内置常用快捷键，比如 ⌃⌘Q 锁屏，也可以自定义），或者什么都不做。
5. 锁屏后按一下手指试试。

### 规则

- 识别成功后**立即执行**这根手指绑定的操作。插着数据线时，用设置入口指纹长按 5 秒会改为打开配置盘，不执行操作。
- 输入密码前会先轻按一下 Shift 唤醒屏幕，再输入密码；可以设置是否在最后按回车。
- 插着数据线连电脑时优先走 USB 输出（更快更稳），否则走蓝牙。
- 设备里已经有指纹时，任何修改都要先在设备上**按一次已录入的手指**，验证后 2 分钟内可以修改。
- 连续 5 次指纹不匹配会锁定 30 秒；之后每多失败 5 次，锁定时间翻倍，最长 10 分钟。
- 添加新电脑：在「蓝牙连接」里点「开放配对」（需要验证指纹），60 秒内在新电脑上完成配对。配对窗口之外，陌生电脑的配对会被立即删除并断开。
- 密码目前只支持英文字母、数字和英文符号（按美式键盘布局输入）。
- **恢复出厂**：设备通电运行时，**长按 BOOT 键 10 秒**，清空所有指纹、密码和蓝牙配对。注意不要按住 BOOT 再插电，那样会进入刷机模式。

## 指纹模块的灯光

**平时使用**
| 灯光 | 含义 |
|---|---|
| 不亮 | 待机 |
| 绿灯常亮，抬手后熄灭 | 识别成功，已经输入密码 / 按了快捷键 |
| 蓝灯闪 2 次 | 识别成功，但这根手指没有绑定操作，或者蓝牙和 USB 都没连上 |
| 红灯闪 2 次 | 指纹不匹配（计一次失败） |
| 红灯闪 3 次 | 连续失败太多，设备暂时锁定中 |
| 蓝灯闪 1 次 | 设备里还没有录入任何指纹 |
| 不亮、没反应 | 这次没按好，重按即可（不计失败） |

**插着数据线，用设置入口指纹长按**
| 灯光 | 含义 |
|---|---|
| 蓝灯常亮 | 正在计时，5 秒内抬手就当普通按一下 |
| 绿灯闪 3 次 | 已满 5 秒，配置盘已经出现 |

**在网页里操作时**
| 灯光 | 含义 |
|---|---|
| 蓝灯呼吸 | 在等你按手指（验证、录入、测试） |
| 绿灯常亮 | 验证成功，或者录入时这一次已经记下，请抬手 |
| 红灯闪 2 次 | 录入时这次没按好，请重按；或者这根手指已经录过了 |
| 绿灯闪 2 次 | 录入完成 |
| 红灯闪 3 次 | 录入失败 |

板子上的橙色小灯只在按住 BOOT 键时快速闪烁，按满 10 秒会恢复出厂设置。

## 已知限制

- 蓝牙配对用的是「LE 安全连接，无需确认码」：设备没有屏幕和按键，无法输入确认码。它能防止配对后被窃听，但配对那一瞬间无法防止有人冒充，所以请在你信任的环境里配对，配对窗口也只开 60 秒。
- 加密钥匙默认存在闪存里，见上面的[安全说明](#安全说明请在使用前阅读)。
- 目前只在 macOS + Chrome 上测试过。

## 代码结构

```
platformio.ini        编译配置
src/config.h          接线引脚和各种参数
src/fp_module.*       指纹模块驱动（海凌科 EF01 串口协议）
src/store.*           账户、指纹信息的存储和密码加密
src/ble_keyboard.*    蓝牙键盘、配对限制和蓝牙配置通道
src/config_drive.*    只读配置盘（FAT12，按需生成）
src/ota.*             在线升级固件
src/main.cpp          识别、输入、配置命令
scripts/embed_web.py  编译前把 web/Settings.html 嵌入固件
web/Settings.html     设置网页（Web Bluetooth；也可以用 Web Serial 通过 USB 连接）
```

网页和设备之间是一行一个的 JSON 命令，蓝牙和 USB 串口内容完全相同，可以在设置网页底部的「通信日志」里看到。
